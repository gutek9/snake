# Manual QA Checklist

## Menu

- App launches to menu with neon title.
- Menu buttons respond to tap.

## Gameplay

- D-pad changes direction (no diagonal moves).
- Eating food increases score.
- Direction change beeps play.

## Game Over + Scores

- Hitting wall triggers Game Over popup.
- Enter initials, save, and see the score in High Scores.
- High score beep plays when you set a new high score.

## Layout

- Left overlay stays in the gutter and shows stats.
- Right overlay shows CODEX/SNAKE title without overlapping board, score, or D-pad.
